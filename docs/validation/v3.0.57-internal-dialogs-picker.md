# Electron 3.0.57 无插件过渡版：内部弹窗与点名修复

HTML 来源：990558219f79a5b92d93a6bc455a91bf75310328；SHA-256：15e80e4b24f10dcc0dba97d5e69bd189ef8add0aecc76f1c861093d7a883f941。程序包、页面可见版本和内部版本均为3.0.57。

## 实现

- 同步无插件网页版：五个主页面、新版自定义主页、名单头像、课程表/资源库、小组配色和独立背景音乐音量。
- 普通功能弹窗全部回到主程序原始DOM；删除DetachedWindows、独立window renderer、对应preload能力及资源路由。不再每120ms克隆并整块替换输入框。
- 隐藏的旧点名面板不参与主页面的焦点锁；设置返回后输入不再被隐藏面板抢焦点。
- 主界面点名按钮显式展开悬浮面板，收起后反复点击仍可打开。
- 图标拖动使用Pointer Events屏幕坐标，主进程校验有限数值，4px阈值、帧合并和最终位置提交；无需系统鼠标位置轮询。鼠标/触屏共用同一实现。
- 面板展开以移动后的图标位置为锚点，并在显示器边缘避让；尺寸仍保存。
- 编辑输入框时，原生失焦不会立刻收起面板，保护系统键盘取焦情形。其他失焦仍自动收起。
- 主窗口依旧唯一拥有抽选、计分、存储及音频。保持三种点名、防重复、六槽赋分、全屏演出、后台运行和安全webPreferences。

## Windows人工复验

1. 打开设置题库编辑、积分与口令窗口，调用屏幕键盘连续输入汉字/数字；确认键盘与输入焦点持续存在。
2. 展开点名，在自定义分值输入时调用屏幕键盘，面板不应自动收起；显式收起按钮仍可用。
3. 用手指慢/快拖动图标，松手后轻点；展开应跟随新位置，屏幕边缘不越界，多屏时使用当前屏幕可用区域。
4. 在PowerPoint前台完成三模式点名、停止揭晓及赋分；主窗隐藏时数据保持同步，关闭演出无残留。
