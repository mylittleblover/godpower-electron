# 3.0.64 悬浮窗与举手候选

2026-11-01；基于 3.0.63 候选 HTML b6981f9、Electron fff94ea。分支 fix/20261101-floating-tools，未推送、未自动合并。计划见 [floating-tools 计划](../../../html/docs/superpowers/plans/2026-11-01-floating-tools.md)。

## 本轮四项修复

1. **点名悬浮窗不再占用任务栏。** 悬浮窗以 `skipTaskbar: true` 创建，并在每次提升层级时重申 `setSkipTaskbar(true)`，Alt+Tab 与任务栏只剩主课堂。
2. **底栏点名直接进入悬浮窗。** `openPickerModal()` 在桌面主渲染进程里不再打开页面内弹窗，而是调用 `desktop.openPicker()`；页面内弹窗继续作为隐藏的抽取引擎（`data-external-picker`，`visibility:hidden`）供悬浮窗驱动。独立按钮「独立点名悬浮窗」和菜单「课堂 → 打开点名悬浮窗」不变。
3. **播放视频/PPT 时仍可置顶。** 悬浮窗使用 `setAlwaysOnTop(true, "screen-saver", 1)` 而不是普通 `floating` 层级，并在展开、收起、拖动、换屏和 `pin` 切换时重新提升；独占全屏程序进入或退出时会重建最顶层，因此收起图标时额外在 1.2s/4.2s 后重申一次层级。绝对置顶仍需真机与具体播放器/PPT 全屏模式确认，见「未覆盖」。
4. **悬浮窗举手入口。** 收起状态点击图标弹出「🎰 点名抽选 / ✋ 举手」启动菜单（窗口 360×200，靠近边缘自动夹回工作区）；举手面板在悬浮窗内选择小组、判对错、用六个槽位或自定义分值加分、抽道具。

## 规则与所有权

举手沿用主课堂已有规则，不新增数据所有者：`handSelect` 只建立带 `selectionId` 的手机会话；`handJudge/handScore/handDraw` 必须携带同一 token，且小组、赛季、`groupUid` 变化即判 `STALE_HAND_SESSION`。判定后不能重复判定；答错不发奖励；加分与抽道具都要求回答正确、课堂未锁定、组非负分、背包未满 3 件。每次举手是一条 `runClassroomCommand` 事务，保存失败即回滚并保持可重试；抽道具复用 `pickItemForGroupV281`、`beginDrawSessionV21710("hand")`、闪电/鱿鱿冷却与首次举手池，失败时恢复抽选会话。主渲染进程持有状态与持久化；悬浮窗只发命令并渲染快照中的 `hand` DTO（经 `sanitizeSnapshot` 白名单、长度与数量上限）。

IPC 新增 `handSelect/handJudge/handScore/handDraw` 四个动作，仍走既有 Broker 的 epoch、序号、重复回执与超时；`gp:window` 新增 `launcher`、`launcherClose`，`expand` 可携带 `picker`/`hand`。

## 本轮修掉的两处自身缺陷

- 曾把「悬浮窗正在呈现」与「原生揭晓可用」混为同一开关，导致桌面端积分揭晓不再弹出；现分离为 `setExternalPresentation`（隐藏引擎标记）与 `setExternalEffectsEnabled`（演出开关），并让页内点名弹窗只在 pick 类型时跳过。
- 收起状态的图标渲染曾整体早退，导致悬浮窗中的滚动条不更新；现收起时仍渲染活动面板，仅隐藏 DOM。

## 本轮用户追加的三项

1. **举手菜单使用道具触发全屏特效。** 底栏「举手办案处」与悬浮窗举手面板使用主道具后都走 `HandItemCinematic`：桌面端经 `gp:item-effect` 交给原生全屏窗口（`kind: "item"`），主窗口收起时也能看到；载荷经 `sanitizeItemFx` 白名单（仅本地 base64 图片、targets 上限 16、整数分值）。浏览器端仍用页面内 `<dialog>`。
2. **七种状态的卡片光圈。** 沿用巨大化/无敌既有呼吸光环样式，每种状态一色：无敌 `#ff4d6d`、巨大化 `#fb923c`、灼烧 `#ef4444`、冰冻 `#22d3ee`、麻痹 `#a855f7`、中毒 `#65a30d`、眩晕 `#e879f9`（另有增益 `#facc15`）。`aura-invincible` 不再与旧 `star` 类型混淆；多状态同时存在时逐层外扩，不再互相覆盖。
3. **悬浮提示乱飘。** 根因是 `body` 上的 `zoom`（视图缩放）与 `position: fixed` + `getBoundingClientRect` 的坐标系不一致，缩放 1.5 时偏差可达 120px。工具提示现挂在 `documentElement` 下未缩放的固定宿主中，任意缩放下都精确对齐。

## 后续追加（同分支第二轮）

1. **固定存档位置与自定义路径。** 主进程 `desktop/save-file.cjs` 在「文档/GodPower/saves/classroom-save.json」维护一份真实文件；每次课堂保存都把同一份已校验信封镜像写盘（临时文件 + 回读校验 + 原子改名，32MB 上限，仅接受绝对 `.json` 路径）。启动时由 `ClassroomSaveFile.hydrate()` 读取：文件有效即压过浏览器缓存，因此换机器只需复制该 JSON；`isHydrating()` 期间课堂保存被推迟，避免把刚拷入的存档覆盖掉。设置「数据与安全」新增路径显示、系统选择器、手填路径、从文件读取、恢复默认；六个 IPC 通道仅 main 角色可用，preload 不接触 `fs`。修掉一处自身缺陷：桥曾在适配器之后内联，导致 `ReferenceError` 使 hydrate 从未执行。
2. **十种全屏特效随机播放。** `EFFECT_STYLES` 定义 aurora/burst/ripple/starlight/spotlight/confetti/vortex/prism/bloom/comet，纯 CSS 层叠加在同一份揭晓标记上。随机在课堂侧发生（`randomEffectStyle()`），点名、计分与道具演出各自抽取；主进程保留显式样式，未知值落回池内。
3. **多目标道具特效全部列出。** 原先 1.5s 逐条轮播，12 个目标要 18 秒；现一次性并列渲染，超过 6 个自动切换紧凑网格，超过 8 个缩小字号，容器限高可滚动。同时修正发动方显示（`caster` 是 `{id,name}`，曾渲染成 `[object Object]`）。
4. **状态替换规则。** 已有状态不可叠加；无敌与巨大化强制替换普通状态，但两者互不替换；任一防御态生效时普通与负面状态一律被挡（`CompetitionEffects.apply` 增加同一守卫）。负面状态仍按「取较长时间」刷新而非累加。
5. **每个道具都有专属卡片动画。** 补齐卡美克（法术交叉光线）、道具箱（礼物弹跳）、问号砖块（放大炸开）三个此前落入通用 `pulse` 的道具，并给所有效果加了冲出卡片的光环冲击波与十片飞散碎片。28 个道具 → 16 个动画族，无一回落。
6. **百科文案。** 补齐卡美克、道具箱的标签，并为火之花、冰之花、回旋镖花、无敌星、巨大蘑菇、卡美克、道具箱重写真正讲战术的「使用技巧」，不再与实际效果重复。
7. **多目标特效平铺展开。** 单目标也曾被旧的 `.item-targets strong`（72px）遗产规则压住并塞进限高盒，出现滚动条与裁切；现改为网格平铺（1/4/12 目标分别 1/2/4 列），`overflow: visible`、无固定高度，实测三种数量都整屏可见且无滚动。顺带修正发动方显示（`caster` 是 `{id,name}`，曾渲染成 `[object Object]`）。
8. **无敌/巨大化清除既有负面状态。** 上一版只拦截「之后施加」的状态，已经挂着的灼烧、眩晕仍与无敌并存（截图中第 8 组同时显示灼烧与无敌）。现在两者生效时直接清空 `competitionEffects`，卡片只留下自己的光环。规则仍为：状态不可叠加、防御态强制替换普通状态、两者互不替换。
9. **分数增加动画改为非线性。** 计数使用 ease-out quint（`1-(1-p)^5`），末位数字缓慢落定而非匀速跳动。

## 第三轮追加

1. **小组头像。** 右侧「···」打开的详情页最顶端新增头像设置，复用其它分区的 `group-detail-section` 样式。读取本地图片为 data URL，校验 PNG/JPEG/WebP 与 512 KiB 上限（`normalizeGroupAvatarV2200` 只接受本地 base64）；设置后卡片的编号方块换成头像、编号移到下方，未设置时沿用成员头像堆叠。课堂锁定时拒绝并提示，不再静默忽略——这一条是自查中发现的缺陷（原实现无反馈直接 return）。
2. **无敌与巨大化改为持续三轮答题。** 生命周期从「抵挡攻击次数」改为 `roundsLeft` 轮次：`CompetitionEffects.arm()` 授予 3 轮，`tickDefensive()` 在每轮结算后递减，到期时 `release()` 释放（巨大化同时腾出主要道具槽）。挡下攻击不再扣减任何计数，因此「从未被攻击的防御」也会正常到期。三条扣减 `hitsLeft` 的旧路径（`item-defense-adapter`、`defense-chain-compat`、`lightning-and-hit-legacy`）改为只挡不扣。
3. **卡片状态只保留名称与剩余轮次。** `labels()` 输出形如「无敌 · 剩余 3 轮」，去掉了「倍率/保分」等后缀；详情页不再重复追加状态名与轮次。
4. **移除卡片冗余文案。** 空闲时的「主要道具可直接点击使用」与使用道具后的小字目标提示都已移除，`v213-result` 行在没有内容时不再渲染；卡片动画（`BattleMotion`）完全未改动。
5. **状态说明移到百科底部并沿用道具卡片样式。** 七种状态改为 `v2170-ency-row` 结构（图标位 + 名称/标签 + 实际效果 + 使用要点），文案精简为规则要点，渲染在 28 条道具之后。

## 未覆盖
