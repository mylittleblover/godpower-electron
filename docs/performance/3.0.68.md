# Electron 3.0.68 性能修复与验收

HTML来源ca1f7c5（完整SHA及SHA-256在resources/BUILD_INFO.json），共享样式来自规范src/styles路径；禁止直接修改发行HTML。本轮包含3.0.67的稳定点名快照和隐藏时钟修复，再加入：

- 隐藏欢迎页延迟DOM渲染，继续发出道具视觉事件；页面进入后显示最新数据。
- 弹窗观察器只检查受影响窗口，保留动态插入、内容替换、焦点、Escape和动画生命周期。
- 主进程存档改FIFO异步磁盘I/O；接受时固定路径及JSON字节，完整读回校验后原子替换，失败保留旧文件，队列继续工作。
- 读取/改存档路径/重置等待已接受写入；正常退出等待队列，关闭主窗口后台运行不变。

性能数据：HTML全量刷新同步中位数106.3→31.1ms（有限合成样本）；8次1MiB存档的主进程事件循环最长间隔32.3/43.1→4.9/5.1ms，心跳0→32/37次。异步总写完时间50–55ms，比同步32–43ms稍长，不宣称磁盘吞吐更高；目标是窗口消息不被I/O整段阻塞。JSON序列化仍在主线程，读入大文件仍有同步成本，异常强杀/断电不保证未完成镜像已落盘。
