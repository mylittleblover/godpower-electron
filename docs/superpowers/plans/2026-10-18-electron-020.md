# Electron 0.2.0 Implementation Plan

**Goal:** 一个业务主窗口、可跨应用使用的点名悬浮窗、独立全屏揭晓窗口。
**Architecture:** HTML 主窗口提供 GodpowerPicker API；Electron 按角色 preload、IPC Broker、WindowManager 分工。
**Tech Stack:** Electron 44.9.0、Node tests、现有 HTML 构建与 Chromium。
**Spec:** ../specs/2026-10-18-electron-020-design.md

## Global Constraints
- 维持原存储 origin、数据格式、26 道具、14 组布局、离线单文件。
- 仅 1920×1080、1x UI 验收；禁止 CircleCI。
- 未运行测试不计通过；Windows 硬件限制明确记录。

## Review Focus
- 刷新期间在途赋分是否被重试而双倍加分。
- 辅助窗能否发送越权 IPC 或从同源存储修改课堂状态。
- 学生/小组删除后旧结果是否仍可赋分。
- 反复关闭覆盖窗是否残留窗口、快捷键或计时器。
- 显示器移除后窗口是否可见。
