# Electron 0.2.0 多窗口点名设计

基线：Electron 22f51f0，HTML origin/main 29966b4；两者 fetch 后没有更新。用户明确授权本会话直接设计、实施、测试、提交和推送，无需分阶段等待确认。

## 唯一业务所有者
主窗口继续使用 classroom://app/index.html 和现有 defaultSession，维持原有 localStorage / IndexedDB。HTML 源码增加 GodpowerPicker 窄接口，直接调用现有抽选、奖池、赋分和声音逻辑；不复制算法。start 在原算法选择一次结果；stop 原逻辑写入防重复池和历史；约一秒减速后 reveal。悬浮窗关闭不取消主窗口抽选；显式取消不提交结果。刷新或崩溃后取消未确认的瞬时抽选，不重新随机、不自动重试赋分。

## 安全通信
三个窗口使用不同 classroom 协议 host；预加载依 role 暴露不同白名单方法。主进程校验 sender / mainFrame / 精确 URL / 消息结构、长度和命令参数。main 仅接收窄命令，picker 只读 DTO；effect 只读已确认结果。所有窗口 sandbox、contextIsolation、webSecurity 开启，Node 集成关闭。请求 ID 以 epoch 去重，过期结果赋分拒绝，主窗口 reload 时所有在途请求失败且不自动重发。辅助窗从不读课堂存储。

## 窗口职责
WindowManager 管理窗口与显示器、独立 shell 配置文件（原子写入），保存悬浮窗尺寸、位置、置顶和特效目标显示器。恢复时将窗口夹回可见屏幕。主窗口关闭退出整个程序；主窗口最小化继续运行。主窗口 renderer 崩溃提供恢复入口，辅助窗崩溃允许关闭重开。

悬浮窗采用青绿/珊瑚紧凑桌面面板：拖动标题区、三模式、滚动转轮、拉杆按钮、奖池与双层预选、六快捷赋分和手输积分、历史、显示器与置顶设置。无新随机行为，显示变化只用主窗口发布的预览。

特效窗每次唯一实例，透明、无边框、置顶，按指定显示器 bounds 铺满，不进入系统独占全屏；showInactive 避免抢走其他教学软件焦点。默认鼠标穿透，跳过按钮悬停才接收鼠标；浮窗跳过和临时 Escape 全局快捷键也能结束演出。550ms 入场、按原设置保持、650ms 退场；中断销毁旧窗/定时器/快捷键。音效仍由主窗口现有 playSound 播放一次，自定义音频无需搬运。尊重减少动画、原特效开关和时长。

## 数据和发行
HTML 改动必须先在 HTML 分支构建、提交；Electron 同步要求干净源码、git 提交、受跟踪 dist 与实际构建相符，记录源码仓库/提交和 SHA-256，启动和打包前校验。保持单文件 HTML 离线运行。Electron 提升至 0.2.0，Windows x64 ZIP 为可用发行格式；安装器尽力构建，当前 Wine32/宿主支持限制如实记录。

## 验收
Node 单测覆盖 IPC、重复消息、过期响应、窗口几何与配置；真实 Electron 运行测试覆盖三模式、同步、减速、赋分、关闭重开、reload、独立覆盖窗和持久化。1920×1080 1x 保存截图并对比 14 组布局 DOM；HTML 核心测试确保 26 道具等旧功能无新增失败。Windows 真机、PPT 覆盖、多显示器硬件与真实听感未执行时记 NOT TESTED。不开启 CircleCI。
